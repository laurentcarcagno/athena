# T-0155 : l'Avancement en cartes

- **Objectif** : l'Avancement d'un projet sur le moteur des tableaux de bord, avec les variantes de carte retenues à la revue (second tour ; ADR-0005 § 2.3).
- **Critères d'acceptation** : indicateurs A, flux cumulé A, vélocité A (et message sans sprint clos), prochaine version C, trackers B, activité A (dédoublonnée, auteur et changement) ; organisable ; tests API et web ; axe sur l'Avancement dans chaque thème.
- **Fichiers** : `apps/web/src/components/ProgressCards.tsx`, `components/Dashboard.tsx`, `pages/DashboardPage.tsx`, `pages/project/OverviewTab.tsx`, `i18n.ts`, tests ; `packages/ui/src/styles/containers.css` ; `apps/api/src/core/dashboard.{service,test}.ts`, `agile/report.{service,test}.ts` ; `e2e/tests/themes.spec.ts`.
