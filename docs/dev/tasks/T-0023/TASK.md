# T-0023 : automatisations et webhooks entrants generiques (phase 7)
- Livre : moteur quand/si/alors (declencheurs artifact.created|updated|transitioned, comment.created, code.linked ; condition ATQL evaluee sur lartefact ; actions commentaire, transition, mise a jour) execute sous lidentite automation:<regle>:<profondeur> au role minimal (workflow et validateurs appliques) ; garde anti-boucle (profondeur 3, pas dauto-declenchement, quota 20 executions par artefact et par heure) ; journal des executions. Webhooks entrants : source par projet, secret HMAC dans le coffre, signature sur le corps brut, tolerance anti-rejeu, idempotence, mappage declaratif sans execution de code (chemins $.a.b[0], gabarits, tables de traduction, protections contre __proto__/constructor), actions create/comment/transition/update sous lidentite inbound:<source>. Routes REST et boucle automatisations dans le worker.
- Constat : lanalyseur JSON de Nest est deja installe, on utilise loption rawBody native.
- Tests : 13 (service) + 1 REST ; 200 au total pour lAPI.
- Non fait : declencheurs planifies (cron), actions webhook sortant/notification/creation, conditions sur lancienne valeur, ecrans de gestion, types de champ de plugin dans le worker (les automatisations sur ces champs echouent ferme), JSONata complet.
